# Workspace Context

This folder stores assistant/workspace context files that are not repository source-of-truth.

## Files

- `HEARTBEAT.md`
- `IDENTITY.md`
- `SOUL.md`
- `TOOLS.md`
- `USER.md`

## Rules

- Product/system truth lives in `docs/`.
- Workspace files are for assistant memory/workflow only.
- Do not move workspace files back to repository root.
